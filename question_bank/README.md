# 内置题库

当前覆盖 CIE AS Chemistry 9701 的 2024、2025、2026 年 February/March，Paper 1 variant 12、Paper 2 variant 22；合计 132 题，300 分。

```text
CIE/9701/AS/
  index.json                     运行索引、覆盖统计、来源和所有题目
  topics.json                    按知识点引用题目 ID（候选分类）
  2024-March/                     2025、2026 同结构
    Paper-1/
      Q01/
        question.pdf             独立题目，保留矢量图形
        answer.pdf               对应官方评分标准裁片
        metadata.json            ID、分值、标签、来源坐标、文件哈希
    Paper-2/
      Q01/                       整道大题；多页按原始阅读顺序
  sources/                       原卷、评分标准、2025–2027 考纲
```

按年份、考季、卷别、题号物理归档。知识点为交叉索引，同一题可有多个标签，不重复复制 PDF。所有题目仍为 `pending_review`；自动切分、答案匹配及关键词分类未经独立逐题复核。Paper 2 保留完整大题及共享条件，未切成可独立选取的小问。旧年份不宣称逐条符合现行考纲。

程序直接加载本目录，不依赖 `data/bank.json`、原作者路径或联网下载。题图预览和组卷主体使用独立 PDF；完整原卷和参考数据使用 `sources/`。请保留整个目录。

来源：项目提供者的本地官方 QP、MS 和考纲资料。来源文件的 SHA-256、封面身份依据、题目原始页序与区域保存在索引中；切片另有文件哈希。原卷题号保留，Paper 1 答案裁片保留原题号及官方字母答案。

## 重建

在项目根目录运行 `python3 scripts/package_bank.py`，从本机 `data/bank.json` 和 `data/sources/` 重建。脚本保留题目 ID 与来源哈希，移除本机绝对路径，不改变内容复核状态。维护者应在变更后运行测试并进行内容复核。
