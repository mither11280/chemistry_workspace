# 题间 v0.4.1

这是 v0.4 的界面改进版，题库格式与 revision 不变，继续使用已有的 2,523 题题库及原 `.qbank` 更新包。

- 编辑页增加独立的“作业名称”区域，配有醒目标签、清晰边框与更大的输入文字；窄窗口也置于操作区之前。
- 题库已选题栏和编辑页均提供“清空已选”。一次移除当前草稿全部题目，保留名称、学生说明和已保存版本。操作后 10 秒内可撤销；再次编辑选题或切换到另一份作业后，旧撤销入口失效。
- 精简题库、选题条件、导出及导入界面中重复的警示与技术说明；考纲信息和校验摘要改为展开查看。文件缺失、实际错误和明确的考纲未知状态继续如实显示。

## 升级

下载 v0.4.1 DMG 后替换 App 即可。个人作业、草稿、原卷及已安装题库位于独立用户目录，保持可用。已安装 v0.4 题库的用户无需重新导入。

首次使用仍先附带 132 题基础资源；需要完整 2,523 题时，在 [v0.4 题库发布页](https://github.com/mither11280/chemistry_workspace/releases/tag/internal-v0.4.0) 下载 `ChemistryWorkspace-v04-full-from-132.qbank`，通过“题库版本与更新”导入。已有 266 题的用户使用对应 `full-from-266` 包。

## 验证

- 56 项 Python 回归测试通过，包括本地真实历年原卷样本；JavaScript 语法检查通过。
- 使用隔离 profile 实际操作：修改名称与说明、添加题目、清空、撤销、刷新后恢复草稿。
- 在 320、375、414、768 和 1280 px 的浏览器 frame 中检查布局，命名框和按钮可用，无文档横向溢出。
- 随 Release 提供最终 DMG 实际安装/重启/升级，以及冻结后端 132→2523 题库兼容性验收报告。

安装包适用于 Apple Silicon macOS；当前仍是 ad-hoc 签名、未经 Apple 公证的预发布构建。许可及完整依赖源代码随附件提供。
