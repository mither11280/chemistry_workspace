# 题间 v0.5.0

按 19 章教学顺序重新整理题库，保留原始 PDF＋公开坐标 JSON＋SQLite＋按需 WebP 架构。

- 4,389 个可用选题单位；68 个待整理项目独立显示。
- Paper 1 保留 2,280 道稳定 ID；Paper 2 从 262 道来源大题拆出 2,177 个计分小问，含重新处理的旧隔离候选。
- 每问按解题所需最靠后章节归类，保存所需章节与判定依据。界面与描述组卷按主章节筛选。
- 必要前问自动连带，共用上下文去重，每小问只计分一次；编辑与导出保留原标签，答案按实际题序输出。
- 首次换代归档旧个人作业、草稿、局部校准和激活状态；新版从空白作业开始，重复安装保留新版作业。
- CIE2 分享代码带题库代际；旧 CIE1 提示回到旧版题库。
- App 及完整题库附件包含全部 231 份已登记授权资料。Git 不保存原卷、缓存和个人数据。
