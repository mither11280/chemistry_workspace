# v0.5.1 实测

在当前 Apple Silicon Mac、隔离资料目录测量。无 WebP 缓存不代表清空操作系统磁盘缓存；首次 SQLite 构建也不等于完整 App 冷启动。

| 项目 | 实测 |
| --- | ---: |
| 整库选题单位 / 原文件 | 7998 / 352 |
| 原文件总大小 | 202,837,951 B |
| 坐标与 Source Manifest JSON | 35,429,987 B |
| SQLite 查询库 | 35,979,264 B |
| 本次预览缓存 | 575,980 B |
| 首次查询库建立 | 3.2438 s |
| 全部7666可用单位的依赖闭包检查 | 2.2447 s |
| 54个预览区域，无WebP缓存 | 1.439 s |
| 同54区域，已有缓存 | 0.0521 s |
| 20小问学生卷 | 0.4294 s / 1,723,526 B / 14页 |
| 同20小问答案卷 | 0.4483 s / 1,068,956 B / 27页 |

20题跨12个章节并含实际跨页题，均无额外计分依赖，选题身份和每次导出结果见[完整测量](performance.json)。参考数据页及官方评分通用原则保留，因此页数不等于选题数。正式导出直接引用原PDF，原资料已有的位图保留。

## 旧格式的同样本对照

实际保留的132道AS旧大题，对应新格式233个选题单位；使用同一批来源题比较，不能按不同的小问数直接平均。

- 旧逐题PDF和元数据：22,454,534 B。
- 对应原卷、JSON和SQLite：9,426,652 B。
- 加入本次WebP缓存：9,763,778 B。

Paper 4没有对应的旧逐题PDF样本，未虚构全量旧存储大小或节省比例。[同样本记录与限制](legacy-storage-comparison.json)。
