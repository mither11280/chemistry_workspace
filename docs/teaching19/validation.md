# v0.5 验证与实际性能

日期：2026-10-28。单台 Apple Silicon Mac，本机授权样本。

## 验证

- 公开索引切换后完整回归：89 项通过。
- 最终真实样本 HTTP 验收通过：19 章筛选、精确小问 ID、依赖闭包及分值、保存与草稿、CIE2 分享、CIE1 旧代际提示、旧个人数据归档、新版空白初始化、重复启动和恢复后新版作业保存。
- 共验证 17 个 QP/MS 预览区域，耗时 0.4162 秒；混合验收卷学生卷 0.1514 秒／323,415 字节，答案 0.1495 秒／204,223 字节。
- 以上验证在独立目录进行，没有修改真实教师个人目录。
- 题库覆盖不等于独立人工内容复核，未据此推算准确率。

## 同一批旧题的存储比较

实际旧资料只有 132 道完整 triplet 可配对；对应新版 233 个单位，其中 229 可用。使用 12 份完整源 PDF，没有按裁片面积估算原卷大小。

| 项目 | 字节 |
| --- | ---: |
| 旧 PDF 与 metadata | 22,454,534 |
| 新完整源 PDF | 6,754,292 |
| 新坐标 JSON | 1,082,408 |
| 新 SQLite／本机文字索引 | 1,536,000 |
| 新总计，不含缓存 | 9,372,700 |
| 20 张 WebP | 338,740 |
| 新总计，含上述缓存 | 9,711,440 |

| 同一批 20 道 Paper 1 | 秒 | 字节 | 页 |

| 新坐标 答案 | 0.0732 | 11,039 | 3 |

旧 metadata 扫描和新 SQLite/FTS 构建不是相同操作，不能当作整机 App 启动速度比较。新导出含来源附录，旧裁片缺少该信息，页数和布局不完全相同。无缓存指没有 WebP，未清空操作系统磁盘缓存。此样本不外推完整历年旧裁片总大小。学生卷没有新增位图对象；MS 保留原 PDF 内已有位图。
